# Image Design

Treat image creation as design, not prompt decoration.

## Process

1. clarify communication goal,
2. identify audience and viewing context,
3. research references,
4. build inspiration panel,
5. define image design DNA,
6. create composition thumbnails,
7. explore distinct visual directions,
8. critique,
9. render/refine,
10. inspect at final usage size,
11. handoff.

## Brief additions

Capture:
- message,
- subject,
- intended emotion,
- crop/aspect ratio,
- placement/context,
- text-safe areas,
- brand constraints,
- required realism/stylization,
- production method.

## Inspiration panel

Reference specific qualities:
- framing,
- camera,
- depth,
- lighting,
- color,
- texture,
- graphic rhythm,
- typography relationship,
- material behavior,
- visual tension.

Do not simply ask for "something like" a living artist or copyrighted franchise. Extract general visual principles.

## Composition first

Create quick thumbnail directions before final rendering.

Vary:
- focal placement,
- scale,
- negative space,
- viewpoint,
- silhouette,
- depth,
- rhythm,
- cropping,
- information density.

## Rendering

When image-generation tools are available, generate iterations deliberately.

Keep a record of:
- concept thesis,
- prompt/spec changes,
- what improved,
- what regressed.

If generation tools are unavailable, produce an executable art-direction brief or prompt package rather than pretending an image was rendered.

## Critique

Review:
- immediate read,
- focal hierarchy,
- silhouette,
- composition,
- lighting logic,
- material plausibility where relevant,
- emotional alignment,
- originality,
- brand fit,
- crop resilience,
- artifacts/errors.

## Handoff

Provide final image(s) or production-ready specification plus intended usage and crop guidance.
