# Design Core templates

Copy and fill these. Delete rows that genuinely don't apply rather than writing "N/A" everywhere. Keep entries short — a template is a thinking aid, not a word count target.

Contents: [Brief](#brief) · [Research log](#research-log) · [Inspiration panel](#inspiration-panel) · [User panel](#user-panel) · [Design DNA](#design-dna) · [Concept card](#concept-card) · [Senior review](#senior-review) · [Synthesis](#synthesis) · [Handoff](#handoff)

## Brief

```markdown
## Brief  — depth: Rapid | Standard | Full
**Problem:** what is wrong or missing today
**Outcome:** what changes for users/business if we succeed
**Deliverable:** the concrete artifact(s)
**Audience:** who, primarily
**Context of use:** where/when/on what device or in what space
**Constraints:** budget, time, tech stack, materials, platform, brand
**Success condition:** how we'll know it worked (observable)
**Assumptions:** what we're taking as true without confirmation
**Known unknowns:** what could change the design if answered
```

## Research log

```markdown
| Finding | Role | Source (date) | Design implication |
|---|---|---|---|
| … | [evidence] / [opinion] / [trend] / [inspiration] / [inference] | … | therefore … |
```

Rules: no row without a source unless it is tagged [inference]. Contradictory findings get their own rows — don't average them away.

## Concept card

```markdown
### Concept <A>: <name>
**Thesis:** one sentence — the core idea
**User benefit:**
**Logic:** how the form / interaction / composition / narrative works
**Distinctive because:**
**Trade-offs:**
**Biggest risk:**
**Fastest test:** cheapest artifact that would expose the risk
```

Check across cards: if two concepts would produce the same wireframe or blockout with different colours, they're one concept.
