# 3D Object Design

Use an industrial-design process: user and package first, silhouette and proportion before surface detail.

## Required stages

1. product brief,
2. user/use-scenario panel,
3. market/reference scan,
4. package/envelope constraints,
5. design DNA,
6. thumbnail/form sketches,
7. architecture concepts,
8. silhouette/proportion development,
9. senior critique,
10. 3D blockout,
11. surface/detail development,
12. CMF,
13. prototype/print/manufacturing review,
14. final presentation/handoff.

## Package and constraints

Define early:
- dimensions,
- human factors,
- internal components,
- interfaces,
- moving parts,
- clearances,
- weight targets,
- structural needs,
- manufacturing process,
- assembly,
- serviceability,
- cost class,
- regulatory/safety concerns where relevant.

Never let styling ignore the package.

## Form development

Work from large to small:

**stance → silhouette → proportion → primary volumes → section logic → transitions → secondary forms → details**

Do not use detail to rescue weak proportion.

## Sketch directions

Create distinct architectures, not cosmetic variants.

Explore:
- mass distribution,
- symmetry/asymmetry,
- hard/soft geometry,
- tension/relaxation,
- protection/exposure,
- monolithic/assembled expression,
- visible/hidden function.

## Surfacing

For refined forms, check:
- section continuity,
- highlights,
- edge strategy,
- part breaks,
- draft/undercut implications,
- touch points,
- dirt/wear zones,
- visual weight.

## CMF

Color, material, and finish should support:
- user context,
- perceived quality,
- durability,
- tactile intent,
- manufacturing reality,
- brand character,
- repair/recycling goals where relevant.

## 3D-print path

When the object is intended for additive manufacture:
- confirm minimum wall thickness,
- overhang/support strategy,
- tolerances,
- orientation,
- bed size,
- assembly joints,
- stress concentrations,
- removable supports,
- material behavior.

Do not claim printability without checking the intended process and material.

## Review

Critique the actual 3D model or render from multiple views, including orthographic-like views when possible.

Check:
- proportion,
- stance,
- usability,
- part logic,
- material transitions,
- manufacturability,
- assembly,
- scale cues,
- consistency with design DNA.

## Handoff

Deliver model/specification plus:
- key dimensions,
- material/finish intent,
- production assumptions,
- unresolved engineering risks,
- prototype recommendation.
