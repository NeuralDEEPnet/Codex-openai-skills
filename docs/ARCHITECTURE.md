# Neuraldeep Design Studio architecture

## Studio model

The system is organized like a multidisciplinary design studio.

### 1. Design Director

The director interprets the brief, chooses the primary discipline, identifies secondary disciplines, sequences the work, and protects coherence across handoffs.

### 2. Design Core

The core defines the shared process, research standards, maturity gates, critique method, and validation lenses.

### 3. Specialist disciplines

- Software Design
- Image Design
- 3D Object Design
- Motion Pictures
- Virtual Worlds

Each specialist owns its medium-specific craft while inheriting the same core process.

## Maturity gates

### Gate 0 — Brief clarity
Required:
- objective,
- audience,
- deliverable,
- context,
- constraints,
- success condition,
- known unknowns.

### Gate 1 — Research grounded
Required:
- user panel,
- inspiration/reference panel,
- relevant competitor/adjacent-category scan,
- evidence vs inference explicitly separated,
- unresolved questions listed.

### Gate 2 — Design DNA
Required:
- 3–5 design principles,
- desired emotional/functional character,
- geometry/composition/hierarchy language,
- material/color/type/motion principles where relevant,
- anti-principles: what the design must not become.

### Gate 3 — Divergent concepts
Create multiple genuinely distinct directions before detailed refinement. A concept is not a color variation.

Each direction states:
- central idea,
- user benefit,
- visual/form logic,
- trade-offs,
- feasibility concerns.

### Gate 4 — Senior review and synthesis
Use multiple critique lenses. Reviewers diagnose; they do not merely vote.

Suggested lenses:
- User Advocate
- Design/Form Director
- Function/Systems Lead
- Feasibility/Engineering Lead
- Accessibility/Responsibility Lead
- Brand/Market Lead

The lead designer synthesizes the critique into a single next-step decision.

### Gate 5 — Prototype/model
Create the cheapest artifact that exposes the biggest design risks.

Examples:
- clickable UI prototype,
- coded page,
- image rough,
- 3D blockout,
- storyboard/animatic,
- spatial greybox.

### Gate 6 — Real-output review
Judge the rendered, coded, simulated, printed, animated, or spatial result—not only source files or intentions.

### Gate 7 — Validation and refinement
Check against:
- user needs,
- original brief,
- design DNA,
- accessibility/responsibility,
- feasibility/performance,
- differentiation,
- emotional and functional quality.

### Gate 8 — Handoff
Deliver:
- final artifact,
- rationale,
- key decisions,
- unresolved risks,
- implementation/production notes,
- and next validation step.

## Critique lenses

The studio uses award-caliber design criteria as critique lenses, not as a fake scorecard:

- purpose and user impact,
- innovation,
- function,
- form and coherence,
- emotional resonance,
- differentiation,
- feasibility,
- craft,
- responsibility,
- accessibility,
- longevity.

Do not claim endorsement by any award organization.
